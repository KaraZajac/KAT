# SMC5326 Protocol

**Rust module:** `src/protocols/smc5326.rs`
**Reference:** Flipper-ARF garage app `applications/system/subghz_garage/protocols/smc5326.c` (primary;
doctor-firmware and ARF's lib copy have the same wire behaviour)

## Overview

SMC5326 / AX5326 encoders: eight trinary DIP switches and four buttons in a 25-bit fixed code. Like
Princeton, the C reports a frame only when it repeats (`last_data`) and estimates the time base (TE) for
the key file and the encoder.

## Timing

| Parameter  | Value              | Notes                         |
|------------|--------------------|-------------------------------|
| te_short   | 300 µs             | ±200 µs                       |
| te_long    | 900 µs             | ±600 µs (3 × te_delta)        |
| Start LOW  | 7200 ± 2400 µs     | encoder guard: 25·TE          |
| End LOW    | ≥ 1800 µs          |                               |

## Frame Layout (25 bits)

MSB first: bit 1 = HIGH 3·TE + LOW TE, bit 0 = HIGH TE + LOW 3·TE; stop HIGH TE; guard LOW 25·TE. Bits
9..24: eight DIP switches of 2 bits (11 = +, 10 = o, 00 = −); bits 1..8: button pairs B1..B4 (11 =
pressed); bit 0. The C keeps no fields (it only displays the DIP rows and pressed buttons); `extra` = TE.

## RF

- **Encoding:** PWM (1:3)
- **RF modulation:** AM (OOK); 315 / 433.92 / 868 MHz
- **Encryption:** none (fixed code)

## Decoder Steps

1. **Reset** — start LOW → SaveDuration (TE sum cleared).
2. **SaveDuration / CheckDuration** — HIGH/LOW pairs added to the TE sum; a LOW ≥ 1800 µs ends the frame:
   25 bits equal to `last_data` (non-zero) are reported with TE = sum / 101. After a decode the app's reset
   needs a new start LOW, while `last_data` keeps the frame (restored after the callback; KAT likewise).

## Encoder

`subghz_protocol_encoder_smc5326_get_upload`, `encoder.repeat` = 3: 25 bits, stop HIGH TE, guard LOW 25·TE,
with the key's TE. No copy can switch buttons; `button` is ignored.

## Key file

`Protocol: SMC5326`, `Bit: 25`, `Key`, `TE: <µs>` (required on load).

## Validation

Garage C oracle (`decode --protocol SMC5326`): 18 identical decodes (key and TE) on the Flipper unit-test
corpus, 217 on 3420 fuzz files; none on IMPORTS. Encoder: 26 uploads (the unit test's `smc5326.sub` with
TE 210 + random keys/TEs) equal both oracles' pulse for pulse.
